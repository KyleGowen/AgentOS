# PR Review Prep State

Minimal local state for the PR Review Prep Agent.

This file may store only lightweight PR tracking metadata so merged PRs are not
reported repeatedly. Do not store PR bodies, raw comments, diffs, customer data,
secrets, or unnecessary work details here.

## Configuration

| Field | Value |

| Default org scope | Measurabl |
