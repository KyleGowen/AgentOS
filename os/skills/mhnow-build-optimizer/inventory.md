# Monster Hunter Now Inventory

Durable owned-gear ledger for Palico. This file is intentionally separate from `saved-builds.md`.

## Capture rule

When Kyle states that he owns an armor piece or weapon, persist it here without interviewing him for the rest of his inventory.

For armor, record when available:

- Exact armor piece name
- Current grade/level
- Driftsmelt skill(s), if stated
- Any relevant notes Kyle explicitly provides

For weapons, record when available:

- Exact weapon name
- Weapon type
- Current grade/level
- Current style, if applicable
- Any relevant customization or notes Kyle explicitly provides

If Kyle gives only partial details, save only what he said. Do not guess missing grades, levels, styles, or smelts. Update the existing entry when he later supplies newer information.

## Recommendation behavior

When Palico recommends a build:

- Check this inventory before presenting the recommendation.
- Clearly mark pieces/weapons Kyle already owns.
- Distinguish owned gear from target/unowned gear.
- Prefer practical upgrade paths that reuse owned gear when the DPS tradeoff is small, but do not sacrifice the optimizer's primary goal without saying so.
- Do not treat a tracked build in `saved-builds.md` as proof that Kyle owns those pieces.
